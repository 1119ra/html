METRIC GLOSSARY

평가 지표의 의미

금융 이상거래 탐지에서 각 지표가 의미하는 바

Precision (정밀도)

이상거래라고 예측한 거래 중 실제 이상거래의 비율 = TP / (TP + FP).

Recall (재현율)

실제 이상거래 중 모델이 탐지한 비율 = TP / (TP + FN).

F1-score

정밀도와 재현율의 조화평균 = 2PR / (P + R).

FP · 오탐

실제 정상거래를 이상거래로 잘못 판단한 건수.

FN · 미탐

실제 이상거래를 정상으로 잘못 판단한 건수.

표준편차 (SD)

동일 오류율에서 3회 반복한 성능이 평균을 중심으로 얼마나 달라지는지 표현.

그룹형 막대그래프결측·시간 오류에 따른 추가 미탐같은 오류율에서 건수 차이를 직관적으로 비교
누적 막대그래프중복으로 인한 평가 기록 팽창원본·추가 중복의 구성과 총합을 동시에 표현
가로 막대그래프원본 컬럼 결측률 비교긴 변수명을 보존하면서 수치 순위 비교

HOW TO USE

사용 방법과 해석 범위

01

데이터 규모 확인

종합 대시보드에서 연도별 거래 분포를 보고 데이터 품질 페이지에서 결측을 점검합니다.

02

오류 유형 선택

오류 실험실에서 결측값·시각 오류·중복 거래와 5·10·20% 조건을 선택합니다.

03

지표 비교

F1·Recall·Precision 평균과 반복 실험 표준편차, FP·FN 집계를 함께 해석합니다.

04

발표와 자료 제출

차트 선택 이유를 설명하고 결과 CSV를 내려받아 웹페이지 및 발표 PPT와 함께 제출합니다.
